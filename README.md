1. Project Overview
For this course, I submitted my Jupyter Notebook that implements a pirate intelligent agent to my GitHub repository. The overall goal of this project was to have reinforcement learning concepts, mainly Deep Q-learning and neural networks, solve a goal-oriented navigation problem. The agent learns how to move through an environment to reach a target efficiently while balancing exploration and exploitation.

2. Work Done
In this project, starter code was provided that defined the environment, the basica structre as well as the overall framework needed to run training episodes as well. meaning that the grid-based world state representation reward structure is used to evaluate the agent. I created and completed the core logic myself, meaning that I implemented the Deep Q network and fine-tuned the neural network and managed experience replay, tuned hyperparameters such as learning rate and discount factor, and controlled exploration strategy using epsilon greedy behavior. I did also work through debugging and iterative testing to ensure that the agents performance improved overtime and that raining results were consistent and explainable.

3. What Computer Scientists do and why it matters
In the aspect of computer science, we design, analyze, and improve systems that solve real-world problems using computation. This matters for modern systems from games to finance, health care, and security. These all rely on intelligent decision-making and automation. Projects like this demonstrate how algorithms can learn from data and adapt over time rather than rely on hard-coded logic.

4. How I approach problems as a computer scientist
I approached these problems by breaking them down into smaller components that are more manageable. I do this in my daily job as a service technician, diagnosing and building computers and laptops. For this project, that means understanding the environment first, the reward structure, as well as the learning algorithm. I relied heavily on testing and iteration to guide changes instead of just guessing. This analytical approach is something I love to apply and plan to continue to do in my day-to-day life and future.

6. Ethical Responsibilities
Ethical responsibilities are a must, as both end users and organizations need standards and trust. Intelligent systems should be transparent, reliable, and used responsibly. A simulated project like this should be understood, and being able to understand how learned behaviors scale to the real world is truly groundbreaking. Poorly designed AI systems will lead to biased decisions, unsafe behavior, or consequences. Ensuring that systems are properly tested and maintained, and that they are also aligned with their proper purpose, is something I now understand.
